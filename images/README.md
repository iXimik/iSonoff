# Фотографии реального SONOFF Basic

Эта папка предназначена для фотографий устройства, которое было перепрошито в рамках проекта **iSonoff**.

| Имя | Что изображено |
|---|---|
| `sonoff-pcb-front.jpg` | Сторона компонентов: реле, кнопка, антенна, ESP8285 и элементы питания |
| `sonoff-housing.jpg` | Оригинальный корпус с наклейкой SONOFF, 90–250 В AC, max 10 A |
| `sonoff-pcb-back.jpg` | Обратная сторона печатной платы и контактные площадки UART |
| `tasmota-off.jpg` | Веб-интерфейс Tasmota 16.0 RU, реле выключено |
| `tasmota-on.jpg` | Веб-интерфейс Tasmota 16.0 RU, реле включено |

На фотографиях открытая плата **обесточена по сетевой стороне**. Никогда не подключайте UART-программатор к реле под напряжением AC.

## Публикация файлов

Пять изображений доступны в архиве `iSonoff_photos_5_for_GitHub.zip`, подготовленном из пользовательских вложений. Для загрузки откройте репозиторий GitHub → папку `images` → **Add file → Upload files**, затем загрузите пять JPG и сохраните изменения.

Либо используйте [PowerShell-скрипт](../scripts/Publish-Photos.ps1) после скачивания архива на локальный компьютер с настроенным доступом к GitHub.

> Фотографии оптимизированы для отображения в README; исходные оригиналы остаются в беседе пользователя. Временные пути ChatGPT не используются как ссылки GitHub.
