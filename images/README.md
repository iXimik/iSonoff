# Фотографии оригинального SONOFF Basic

В документацию включены три пользовательские фотографии реального устройства:

1. `sonoff-pcb-front.jpg` — сторона компонентов (Wi-Fi-антенна на PCB, ESP8285, кнопка, индикатор, силовое реле и элементы блока питания).
2. `sonoff-housing.jpg` — пластиковый корпус со старой этикеткой SONOFF Wi-Fi smart switch, питание 90–250 В AC, максимальная нагрузка 10 А.
3. `sonoff-pcb-back.jpg` — обратная сторона платы с контактными площадками UART и изоляционными прорезями.

**Год выпуска:** около 2016 года — описание владельца; фотография и этикетка не дают независимого подтверждения даты.

## Как опубликовать изображения

Архив `iSonoff_photos_for_GitHub.zip` подготовлен в беседе ChatGPT из трёх исходных JPG без изменения содержания. GitHub API-коннектор в этом сеансе поддерживает создание текстовых файлов и Git-объектов, но не предоставил прямой доступ к бинарным байтам изображений из вложений. Поэтому имена и места в README подготовлены, однако **пока изображения не загружены**. Для загрузки:

1. Скачайте ZIP и распакуйте; внутри есть директория `images/` с тремя JPG.
2. В GitHub откройте `iXimik/iSonoff` → `Add file` → `Upload files`.
3. Перетащите три файла в папку `images/` (или в локальном Git-репозитории скопируйте файлы и отправьте `git push`).
4. Убедитесь, что рисунки появились в `README.md`.

Альтернативный вариант — запустить [скрипт публикации](../scripts/Publish-Photos.ps1) на компьютере с установленным Git и настроенной аутентификацией GitHub.

## Безопасность

На фотографиях открытая силовая плата. **Никогда не подключайте сетевые 220 В к разобранному SONOFF при подключённом USB-UART.** Публикация фотографий не означает разрешения на такую схему работы.
