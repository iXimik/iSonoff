# 05. Первый запуск, Wi-Fi, веб-интерфейс и тест реле

## 1. Запуск Tasmota

После успешной записи (`Hash of data verified`):

1. Отключить питание 3,3 В.
2. Убедиться, что штатная кнопка отпущена (GPIO0 не замкнут на землю).
3. Подать питание 3,3 В от **достаточно мощного** источника — без участия сети 220 В.
4. Найти на телефоне временную сеть Tasmota (часто `tasmota-XXXXXX-####`).
5. Подключиться и открыть `http://192.168.4.1`, указать Wi-Fi своей домашней сети **без публикации пароля**.

В реальном эксперименте Tasmota была дополнительно проверена в домашней сети со штатным питанием **после отсоединения программатора**; устройство должно быть полностью закрыто и электробезопасно собрано до подключения к AC.

## 2. Найти устройство по DHCP

Открыть список DHCP-клиентов домашнего роутера. В эксперименте на роутере TP-Link был виден хост вида `tasmota-XXXXXX-####` и выдан локальный IPv4-адрес. Устройство открылось по `http://<IP-SONOFF>`.

Для повторного проекта рекомендуем DHCP-reservation в роутере вместо жёсткой привязки к IP в коде. **Настоящий SSID, IP и MAC устройства намеренно не опубликованы здесь.**

## 3. Проверить прошивку и профиль

На главной странице устройства показаны `Sonoff Basic` и `Tasmota 16.0.0`.

«Настройки» → «Настройки модуля» — проверить профиль **Sonoff Basic (1)**, не изменять назначение GPIO без понимания ревизии платы.

«Информация» — проверить контроллер ESP8285, Flash 1024 KB, версию Tasmota, статус Wi-Fi, uptime и память.

## 4. Проверить переключение реле

**Только при безопасной сборке**: закрытый штатный корпус, снят USB-UART, закрыты все сетевые контакты, сетевые подключения проверены квалифицированным специалистом, нагрузка на выходе отсутствует.

1. Нажать «Переключить».
2. `OFF` должен смениться на `ON`, слышен щелчок механического реле, меняется индикатор.
3. Нажать ещё раз: `ON` → `OFF`, повторный щелчок.

**В эксперименте все эти признаки подтверждены.** Факт щелчка не заменяет электрическую проверку контактов при рабочей нагрузке; с нагрузкой не экспериментировали.

## 5. Резервное копирование новых настроек

В Tasmota: «Настройки» → «Резервное копирование настроек». Сохранить файл **локально** и не публиковать. Это файл настроек Tasmota, **не** полный первоначальный бинарный дамп 1 MB.

## 6. Безопасность сети

- Ограничить доступ к веб-интерфейсу доверенной локальной сетью.
- Установить пароль администратора Tasmota в настройках, хранить секрет отдельно.
- Не открывать порт 80/1883 в интернет.
- Учитывать, что **обычный HTTP не шифрует команды/пароли**.
- Для реальной автоматизации предпочтительнее локальный MQTT-брокер с аутентификацией и сетевой изоляцией.

### Важная точность: «HTTP API — Блокирован»

На информационном экране эксперимента выведено `HTTP API: Блокирован`. Не делайте вывода, что `SetOption128` является «общим выключателем HTTP API»: согласно документации, **SetOption128 управляет проверкой HTTP Referer** (1 по умолчанию), а не всем API. Выяснять реальный статус HTTP API следует отдельно; **не отключайте проверку Referer без необходимости**.
