# Фотографии и скриншоты проекта iSonoff

Все **пять изображений опубликованы непосредственно в репозитории** и встроены в главный [README.md](../README.md).

| Файл | Содержание |
|---|---|
| [sonoff-pcb-front.jpg](sonoff-pcb-front.jpg) | Лицевая сторона платы старого SONOFF Basic: ESP8285, реле, кнопка, светодиод и антенна |
| [sonoff-housing.jpg](sonoff-housing.jpg) | Заводской пластиковый корпус с маркировкой 90–250 В AC, максимальная нагрузка 10 А |
| [sonoff-pcb-back.jpg](sonoff-pcb-back.jpg) | Обратная сторона платы, дорожки, изоляционные прорези и отладочные площадки |
| [tasmota-off.jpg](tasmota-off.jpg) | Установленная Tasmota 16.0.0 RU — состояние OFF |
| [tasmota-on.jpg](tasmota-on.jpg) | Установленная Tasmota 16.0.0 RU — состояние ON |

Фотографии предоставлены владельцем устройства. Изображения оптимизированы для веб-просмотра в GitHub; это не технические чертежи. Точная дата выпуска экземпляра по фотографиям не подтверждена: ориентир **2016 год** относится к поколению устройства.

> **Безопасность:** открытая плата на фотографиях показана для осмотра, а не для работы от сети. Не соединяйте UART с устройством под сетевым напряжением. Включение в сеть допустимо только после полного отключения программатора, восстановления корпуса и проверки силовой проводки.

Дополнительный [PowerShell-скрипт](../scripts/Publish-Photos.ps1) позволяет повторно загрузить изображения из локального ZIP, если потребуется восстановить содержимое папки. При обычном просмотре репозитория запускать его не нужно.
